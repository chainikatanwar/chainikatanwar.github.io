# Chainika Tanwar — Product Portfolio

A static portfolio site, ready for GitHub Pages.

## Files
- `index.html` — the whole site (styles included)
- `assets/chainika.jpg` — profile photo (also embedded in `index.html`, so the page works on its own)

## Publish on GitHub Pages
1. Create a public repository named `chainikatanwar.github.io`.
2. Click **Add file → Upload files**, drag in `index.html`, `README.md` and the `assets` folder, then **Commit changes**.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. After a few minutes, open `https://chainikatanwar.github.io`.

To update the site, edit or re-upload `index.html` and commit.
